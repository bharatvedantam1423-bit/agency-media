Agency Signal Lens · Settings

1. Laya (free, runs on your computer)

Laya reads each post and decides if it's AI slop, specific or vague, and about design. Without it, the extension uses quick text rules.

  1. Install Python 3.10+ once, then in Terminal run:
    pip install "laya[serve]"
laya-serve
  2. Leave that Terminal window open while you browse. The first start downloads the model (a few minutes).

2. Send posts to the Agency Signal dashboard (optional)

Live posts you see get added to your dashboard, so it stays fresh even where public data is old (like X).

Good to know

Auto-scrolling social sites for long stretches can look automated to them. Use a normal pace, and use a secondary account if you're worried about your main one.
